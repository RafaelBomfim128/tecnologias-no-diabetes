Gerador de QR Code para Smart 2 com Juggluco

Utilize esta ferramenta quando estiver com dificuldades para escanear o QR Code do Smart 2 no aplicativo Juggluco

💡

Este é um método utilizado quando você está com dificuldades de ler o QR Code apresentado na caixa do Smart 2 com o Juggluco. Deve ser feito em um computador, celular ou tablet diferente do celular que está sendo escaneado.

Como usar:

  1. Insira os dígitos exatamente como aparecem na caixa ou no aplicativo Smart
  2. O QR Code será gerado automaticamente
  3. Escaneie o QR Code gerado com o aplicativo Juggluco
