Transparência e Responsabilidade

Esta ferramenta existe única e exclusivamente para ajudar usuários a visualizar as glicemias do seu Nightscout, a fim facilitar a visualização de glicemias exatas de dias anteriores. Entendemos que a API Secret é um dado sensível e, como tal, será tratada com total sigilo e não será enviada ou tramitada para lugar algum sem o consentimento pleno do usuário. Apenas a URL pode ser enviada para um proxy nosso para contornar um problema de política de CORS. Ainda assim, caso não se sinta confortável, não a utilize.
